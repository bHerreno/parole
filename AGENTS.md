# Data security rule

Use only TabErrans data for real-media tests, demonstrations, benchmarks and published evaluations.
Never copy, commit, upload or mention other personal recordings, their identifiers, paths, derived outputs or evaluation results.
Mathematical unit-test fixtures contain no real personal data.
Before publication, inspect staged files and outgoing commits for media, logs, generated results and private-data references.
Do not publish environment directories or incidental local outputs. Preserve original files outside this workspace.

Distributed CI examples must be fully synthetic, never recordings or excerpts of real people. Do not commit or upload real videos. Keep repository instructions and CI paths relative; never hard-code personal home or workspace paths. Runtime paths may be derived from the checkout location.
